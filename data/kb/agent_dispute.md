# Agent dispute — fictional demo policy

Category: agent_dispute

**SYNTHETIC / FICTIONAL DEMO ONLY — مو سياسة حقيقية لزين كاش.**

إذا الشحن أو السحب عند الوكيل ما انحسب، أو الزبون يعترض على عمولة، اجمع وصف المشكلة ومرجع الوصل غير السري من التذكرة. قارن المبلغ بالسجل التجريبي إذا موجود، وخلي الزبون يحتفظ بالوصل للمراجعة بالقناة الرسمية بدون نشر بياناته.

وجّه الشكوى لفريق Agent Network. لا تحكم إن العمولة صحيحة أو مخالفة من دون مصدر معتمد، ولا تطلب دفعة ثانية لحل المشكلة. صعّد أي تضارب بالسجل أو شبهة احتيال لمراجعة بشرية، ولا توعد بتعويض أو موعد حسم.

لا تطلب رمز التحقق OTP أو الرقم السري PIN أو كلمة المرور. هذا دليل عرض خيالي، وما يحدد رسوم أو ضمان تعويض أو صلاحية دخول لأي حساب حقيقي.
