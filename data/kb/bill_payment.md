# Bill payment — fictional demo policy

Category: bill_payment

**SYNTHETIC / FICTIONAL DEMO ONLY — مو سياسة حقيقية لزين كاش.**

إذا دفع فاتورة الكهرباء أو الانترنت أو شحن الرصيد ظاهر ناجح بالسجل التجريبي والجهة بعدها تكول مو مدفوع، فرّق بين حالة العملية وبين تأكيد الجهة المستفيدة. استخدم مرجع العملية والمبلغ الموجودين بالتذكرة أو السجل المطابق فقط.

لا توصي بدفع الفاتورة مرة ثانية قبل التدقيق. وجّه الحالة لفريق Payments Ops حتى يراجع المطابقة مع الجهة. إذا ماكو عملية مطابقة، اشرح إن التأكيد ناقص وصعّدها لإنسان. لا توعد بوقت تسوية أو رجوع مبلغ ولا تدّعي إن الفاتورة تسددت عند الجهة.

لا تطلب رمز التحقق OTP أو الرقم السري PIN أو كلمة المرور. هذا دليل عرض خيالي، وما يحدد رسوم أو ضمان تعويض أو صلاحية دخول لأي حساب حقيقي.
