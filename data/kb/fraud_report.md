# Fraud escalation — fictional demo policy

Category: fraud_report

**SYNTHETIC / FICTIONAL DEMO ONLY — مو سياسة حقيقية لزين كاش.**

إذا واحد اتصل وادّعى إنه موظف وطلب الرمز، أو أكو سحب أو حركة الزبون ما سواها، اعتبرها شبهة احتيال تحتاج إنسان بأولوية عالية. انصح الزبون يوقف التواصل ويا المتصل وما يشارك أي رمز جديد، ويتواصل من داخل التطبيق أو قناة رسمية يتحقق منها بنفسه.

خلّي التصعيد لفريق Account & Security مستمر حتى لو نكتب مسودة مساعدة. لا تلوم الزبون، ولا تعيد ذكر الرمز اللي شاركه، ولا تدّعي تجميد الحساب أو إيقاف العملية. لا توعد باسترجاع أو تعويض، ولا تحول شبهة الاحتيال إلى استفسار عادي.

لا تطلب رمز التحقق OTP أو الرقم السري PIN أو كلمة المرور. هذا دليل عرض خيالي، وما يحدد رسوم أو ضمان تعويض أو صلاحية دخول لأي حساب حقيقي.
