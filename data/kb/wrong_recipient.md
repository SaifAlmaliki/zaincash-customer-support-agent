# Wrong recipient — fictional demo policy

Category: wrong_recipient

**SYNTHETIC / FICTIONAL DEMO ONLY — مو سياسة حقيقية لزين كاش.**

إذا الزبون حوّل لرقم غلط بالغلط، هاي مراجعة نزاع مو عطل تحويل تقني. راجع رقم العملية والمبلغ ورقم المستلم المذكورين بالتذكرة مقابل السجل التجريبي، ولا تكشف معلومات شخص ثاني. وضّح إن فريق Disputes يحتاج يراجع الحالة قبل أي قرار.

لا توعد بإلغاء التحويل أو رجوع الفلوس، ولا تطلب من الزبون يدفع مبلغ إضافي حتى يسترجعها. إذا أكو ضغط أو تهديد أو شبهة نصب، خلّي التصعيد البشري واضح ومستمر.

لا تطلب رمز التحقق OTP أو الرقم السري PIN أو كلمة المرور. هذا دليل عرض خيالي، وما يحدد رسوم أو ضمان تعويض أو صلاحية دخول لأي حساب حقيقي.
