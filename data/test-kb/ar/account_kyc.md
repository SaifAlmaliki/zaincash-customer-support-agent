# توثيق الحساب — سياسة خيالية للعرض التجريبي

معرّف الفئة: account_kyc

**محتوى مصطنع وخيالي للعرض التجريبي فقط — مو سياسة حقيقية لزين كاش.**

إذا السؤال عن توثيق الحساب أو رفض الهوية أو رفع مستوى الحساب أو تغيير معلوماته، وجّه الزبون لمسار التوثيق داخل التطبيق الرسمي. خليه يوصف سبب الرفض الظاهر بدون إرسال صورة هوية أو مستمسكات بمحادثة الدعم التجريبية.

فريق الحسابات والأمان يراجع الحالات غير الواضحة بشرياً. هذا المصدر ما يحتوي قائمة مستمسكات معتمدة أو حدود مالية حقيقية؛ إذا السؤال يحتاج هاي التفاصيل، بيّن إن ما عدنا مصدر موثوق هنا وصعّده. لا توعد بالموافقة أو تدّعي تعديل الحساب.

لا تطلب رمز التحقق OTP أو الرقم السري PIN أو كلمة المرور. هذا دليل عرض خيالي، وما يحدد رسوم أو ضمان تعويض أو صلاحية دخول لأي حساب حقيقي.
