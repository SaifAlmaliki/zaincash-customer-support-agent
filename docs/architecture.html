ZainCash Support Pipeline

Classify, retrieve, and draft. A person approves every reply. Nothing is sent automatically.

Cascade

  • • Jev returns one of 12 categories, priority P1–P4, six flags, and span picks that already appear in the ticket.
  • • A second call repeats only the category, with the options reversed.
  • • Uncertain when the label is invalid, the top probability is under 0.60, confidence is under 0.60, or those two calls disagree.
  • • Cascade mode then calls Gemini. A Jev failure in cascade mode does too. Jev-only mode does not.
  • • Gemini runs the same prompt three times at temperature 0.7. Confidence is the winning count divided by 3. Below 0.66 is uncertain.

Grounded draft

  • • The draft node is a LangChain agent on Gemini through OpenRouter. It writes Iraqi Arabic from policy passages and the matched transaction.
  • • At most six read-only tool calls, finished within 30 seconds. No tool changes a financial record.
  • • Policy search uses pgvector. Embeddings are text-embedding-3-small, 768 dimensions, also through OpenRouter.
  • • Uploaded policies are parsed and indexed outside the ticket graph.
  • • RAG_ENABLED=false and --no-db stay classification-only.

Safety

  • • prepare folds Arabic-Indic digits to 0–9 and masks card numbers before storage.
  • • extract keeps a value only when it matches a span of the original text.
  • • Fraud, low confidence, disagreement, missing details, a transaction mismatch, and a failed draft check all escalate. The team is still assigned.
  • • Guardrails require a policy citation and allow only numbers from the ticket or the transaction. Jev checks credential wording.
  • • The workspace approves, edits, or rejects. A person sends the reply. The pipeline has no send step.
