ZainCash Support Pipeline

Local back-office pipeline · classify, extract, match the transaction, route, then a person approves

Cascade

  • • Jev runs first in jev and cascade mode
  • • Confident only if the top label, the score, and the reversed-option check agree
  • • Otherwise Gemini answers three times; two of three must agree
  • • A remaining disagreement is escalated with a one-line note

Safety

  • • Card numbers are masked before anything is stored
  • • An extracted value must appear in the ticket text
  • • Fraud, missing details, and transaction mismatches escalate
  • • The agent copies an approved reply; the system never sends it

Runtime

  • • Workspace on :5173, API on :8000, Postgres on :5433
  • • The CLI and the UI call the same LangGraph graph
  • • Jev is jev-1.13.0 via TypeSafe; Gemini is Gemini 3.8 Flash via OpenRouter
  • • Reply drafting is still NullDrafter; RAG is the next stage
